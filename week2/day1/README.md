#  SQL Practice Repository

A collection of beginner-to-intermediate SQL practice queries built using **MySQL Workbench**.
This repository includes table creation, data insertion, and real-world query examples using functions, conditions, and date operations.

##  Topics Covered

* Database & Table Creation
* INSERT Queries
* String Functions
* Date Functions
* Aggregate & Conditional Logic
* CASE Statements
* Salary & Loan Calculations
* Customer & Subscription Analysis

## Tables Included

* `employee_payments`
* `orders_delivery`
* `customer_spending`
* `subscriptions`
* `loan_details`

## Skills Practiced

* Data Formatting
* NULL Handling
* Date Calculations
* Business Logic Queries
* Financial Calculations
* Query Optimization Basics

## Tech Used

* MySQL
* MySQL Workbench

## How to Run

1. Open MySQL Workbench
2. Create or select a database
3. Run the `.sql` file
4. Execute queries section by section
