
# PySpark Phase 4A – Bucketing & Segmentation

This project demonstrates different bucketing and segmentation techniques in PySpark using customer spending data. It categorizes continuous values into meaningful business segments like **Gold**, **Silver**, and **Bronze** for better analysis and decision-making. :contentReference[oaicite:0]{index=0}

## 🚀 Technologies Used

- Python
- PySpark
- Apache Spark
- Databricks

## 📌 Methods Implemented

- **Conditional Logic** using `when()` and `otherwise()`
- **SQL CASE Statement**
- **Bucketizer (MLlib)**
- **Quantile-Based Segmentation** using `approxQuantile()`
- **Window Functions** using `percent_rank()`

## 📊 Features

- Customer segmentation into Gold, Silver, and Bronze
- Dynamic and fixed threshold bucketing
- SQL and DataFrame implementations
- Percentile-based customer ranking
- Customer count by segment
